# Pausing new self-serve signups for GitHub Copilot Business

---

## What's deprecated

**New self-serve signups for GitHub Copilot Business** are paused for organizations on **GitHub Free and GitHub Team plans**, effective April 22, 2026. This is a temporary measure to protect service quality for existing customers.

| Affected | Not affected |
|---|---|
| New self-serve signups (GitHub Free / Team plans) | **Existing Copilot Business customers** |
| New seat additions via self-serve for new orgs | **Adding seats to existing subscriptions** |
| New sign-up flow on github.com for eligible orgs | **GitHub Enterprise customers** |

### Action required

- **New organizations wanting Copilot Business** → wait for GitHub to resume signups; watch for announcements
- **Existing Copilot Business customers** → no action required; add seats and use all features as normal
- **Enterprise customers** → not affected; Copilot Enterprise and enterprise-level Copilot Business continue normally

### Timeline

- **April 22, 2026** — self-serve signups paused for GitHub Free/Team plan organizations
- **TBD** — GitHub will announce when signups resume
