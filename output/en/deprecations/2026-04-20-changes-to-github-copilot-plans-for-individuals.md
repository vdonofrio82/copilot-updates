# Changes to GitHub Copilot plans for individuals

---

## What's deprecated

New sign-ups for **Copilot Pro**, **Copilot Pro+**, and **Student plans** are **paused as of April 20, 2026** due to increased compute demand from agentic workflows. Certain premium models are removed from lower-tier plans.

| Change | Affected plan(s) |
|---|---|
| New sign-ups paused | Copilot Pro, Pro+, Student |
| Opus models removed | Copilot Pro |
| Opus 4.5 and 4.6 to be removed | Copilot Pro+ |
| Usage limits tightened | Copilot Pro, Pro+, Student, Free trial |

### Action required

- **Existing subscribers dissatisfied with changes** → cancel and request a refund via Settings → Billing and licensing → Licensing → Manage subscription (available until **May 20, 2026**)
- **New users wanting Copilot** → Copilot Free remains available for new sign-ups
- **Teams monitoring usage** → check VS Code and Copilot CLI usage alerts as new limits take effect
- **Admins reviewing model access** → audit which Opus models are still accessible on current plans

### Timeline

- **April 20, 2026** — new Pro, Pro+, Student sign-ups paused; Opus models removed from Pro
- **Soon** — Opus 4.5 and 4.6 removed from Pro+
- **May 20, 2026** — deadline to request refund for existing Pro/Pro+ subscribers
