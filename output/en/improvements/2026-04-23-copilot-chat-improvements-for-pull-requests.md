# Copilot Chat improvements for pull requests

---

## What changed

**Copilot Chat** can now **understand, review, and summarize pull requests** using the full context of PR comments, commits, file changes, and reviews — directly from github.com.

### Why it matters

- **Full PR context** — Copilot reads PR comments, file changes, commits, and reviews for more relevant, accurate responses
- **Structured PR review** — ask Copilot to review a PR and receive a structured breakdown with detailed feedback
- **Instant PR summary** — get a concise, human-readable overview of any PR in seconds
- **Works anywhere on github.com** — available via global Copilot navigation or at github.com/copilot
- **Richer diff experience** — public preview users can click the Copilot button on a diff and ask contextual questions

### How to get started

1. Open any **pull request** on github.com
2. Open **Copilot Chat** via the global Copilot navigation button
3. Try suggested prompts like **"Help review this pull request"** or **"Summarize this PR"**
4. For diff-specific questions: click the **Copilot button on a diff** (public preview users)

### Who gets it

- **All Copilot subscribers** — available now on github.com
- **Diff Copilot button** — public preview users
