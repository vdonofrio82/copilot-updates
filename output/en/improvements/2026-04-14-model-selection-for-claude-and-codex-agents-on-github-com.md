# Model selection for Claude and Codex agents on github.com

---

## What changed

**Claude and Codex third-party coding agents** on github.com now support **model selection**, letting developers choose the specific Anthropic or OpenAI model powering their agent tasks.

### Why it matters

- **Precise model control** — match the model to the task, balancing capability against cost
- **Broad Claude support** — Claude Sonnet 4.6, Claude Opus 4.6, Claude Sonnet 4.5, Claude Opus 4.5 available
- **Broad Codex support** — GPT-5.2-Codex, GPT-5.3-Codex, GPT-5.4 available
- **Included with existing subscriptions** — no additional cost for the model selection capability

### How to get started

1. Navigate to your repository's **Settings → Copilot → Cloud agent**
2. Ensure the Claude or Codex agent is enabled for your repository
3. For **Business / Enterprise**: have your admin enable the Anthropic Claude or OpenAI Codex policy
4. Select your preferred model from the agent configuration

### Who gets it

- **All Copilot subscribers** with Claude or Codex agent access — available now
- **Business / Enterprise** — requires admin policy enablement for Claude and Codex agents
