# GPT-5.5 is generally available for GitHub Copilot

---

## What's new

**GPT-5.5** by OpenAI is now **generally available** in GitHub Copilot, delivering the strongest performance yet on complex, multi-step agentic coding tasks with a **7.5× premium request multiplier**.

### Why it matters

- **Best agentic performance** — GPT-5.5 excels at multi-file refactors, long tool-rich sessions, and real-world coding challenges previous GPT models couldn't solve
- **Multi-surface picker** — select GPT-5.5 from the model picker in VS Code, Visual Studio, Copilot CLI, github.com cloud agent, GitHub Mobile, JetBrains, Xcode, and Eclipse
- **Gradual rollout** — broad availability rolling out now; eligible plan users may need to check back if the model isn't visible yet

### Where you can use it

- **VS Code, Visual Studio, JetBrains, Xcode, Eclipse** — via the inline model picker
- **Copilot CLI** — select GPT-5.5 from the CLI model picker
- **github.com cloud agent** — for complex multi-step agentic tasks
- **GitHub Mobile** — iOS and Android

### Who gets it

- **Copilot Pro+, Business, and Enterprise** — available now
- **Business / Enterprise** — plan administrators must enable the GPT-5.5 model policy in Copilot settings
- **Pricing** — 7.5× premium request multiplier applies
