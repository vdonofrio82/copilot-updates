# Research, plan, and code with Copilot cloud agent

---

## What's new

**Copilot cloud agent** now supports branch-based workflows, **implementation planning**, and **deep research sessions** — no pull request required to get started.

### Why it matters

- **Branch-first workflows** — work directly on a branch and open a PR only when ready, removing forced PR overhead
- **Plan before code** — review and approve an implementation plan before Copilot writes a single line, reducing wasted effort
- **Deep research** — ask high-level questions about your repo and get context-aware answers grounded in real code
- **Verified commits** — every Copilot commit is now cryptographically signed as "Verified" for audit trail integrity
- **Built-in security** — a prompt-injection firewall prevents data leaks from malicious inputs

### Where you can use it

- **github.com Agents tab** — start research and coding sessions directly from any repository
- **Copilot Chat** — trigger research sessions inline from the chat interface
- **Issues and PRs** — assign issues or mention @copilot to kick off branch-based agent tasks

### Who gets it

- **All paid Copilot plans** — included for Copilot Pro, Pro+, Business, and Enterprise
- **Business / Enterprise** — admins must enable the Copilot cloud agent policy before users can access it
- **Available now** — all features live as of April 1, 2026
